- New scene geometry differs from the source. Day and night counterparts share the new candy-shop setting; shop2 has a caramel palette correction.
- New backgrounds use somewhat more line detail than the original while keeping the limited pastel palettes.
- English title lettering uses tight decorative spacing. The eight Chinese title characters were visually checked.
- Source author logo is replaced by a new candy emblem; the original author credit remains in the report.
- The source uniform transition color is represented by a newly generated dark tile, with slight tonal texture.
- Effects are new interpretive redraws. The memory filter uses sparse cream flecks rather than an identical source texture.
- Animation cells are three new phases; timing is documented separately in the source analysis.
- Intentional thumbnail reuse of a newly generated background or character pose, rendered with CSS UVs. This is not a separate image generation.
- Original smooth unclothed candy-body state is intentionally replaced by a fully opaque, modest pink frosting dress with short sleeves and a closed neckline.
- Generated canvas dimensions are not exactly divisible by the requested grid; use normalized per-cell UVs with source rounding, not integer cell-size multiplication.
