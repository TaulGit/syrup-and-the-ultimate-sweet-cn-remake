# 希乐普与终极糖果 · 中文网页重制

一位相信科学的制糖师，遇见了一个会说话的糖果女孩。十九处选择，十种结局，一份不能只用配方解释的甜。

![糖果工坊封面](assets/cover.png)

本项目参考 [NomnomNami 的原作《Syrup and the Ultimate Sweet》](https://nomnomnami.itch.io/syrup-and-the-ultimate-sweet)，通过公开网页构建的 REA 分析，重新实现分支规则，并制作新的中文对白、视觉素材与浏览器界面。

这是**保留关键分支规则的精简中文改编**：共 51 个场景、130 段对白，保留 19 处选择、40 个选项、10 个结局及关系分数、条件救援、跨周目解锁。对白重新编写，分镜节奏有所调整；没有逐句移植原作剧本，也没有嵌入原作 Ren’Py 引擎。

## 功能

- 中文视觉小说：角色立绘、场景背景、绘本式剧情插画与结局收藏。
- 存读档：6 个普通槽、1 个快速槽、1 个自动槽，支持 JSON 进度导入与导出。
- 阅读辅助：回退、对白历史、自动播放、已读快进、文字速度与字号设置、减少动画。
- 新视觉素材：33 张最终 PNG 图集，覆盖中文版所需的 397 个源素材槽位。
- 素材研究室：按分类、角色和状态筛选，查看原文件索引、新图槽位、提示词及剧情条件。
- 星匣适配：接入 GameSDK 用户存储；本机独立运行使用浏览器存储。

## 快速开始

需要 **Node.js 20 或更新版本**。项目没有 npm 运行时依赖，无需执行 `npm install`。

在项目根目录运行：

```sh
npm start
```

然后打开：

- [游戏](http://127.0.0.1:4173/)
- [素材研究室](http://127.0.0.1:4173/preview/)

开发服务默认只监听本机回环地址，端口为 `4173`，可通过 `PORT` 环境变量调整。请通过 HTTP 服务打开项目；直接双击 HTML 文件无法正常读取模块和素材索引。

## 操作

| 操作 | 方式 |
|---|---|
| 推进对白 | 点击对话框、空格键；文字尚未显示完时，首次点击立即显示全文 |
| 选择选项 | 点击按钮，或按数字 `1`–`3` |
| 回退 | 方向键 `←`，或界面中的回退按钮 |
| 打开菜单 | `Esc`，或菜单按钮 |
| 自动与快进 | 使用底部按钮；快进默认只跳过已读对白，并在选项处停止 |
| 调整阅读体验 | 在设置中调整文字速度、字号、自动间隔与减少动画 |

轻音乐由浏览器程序合成，默认静音，可在设置中调整音量。

## 构建与测试

```sh
npm run build
npm test
```

构建会检查素材覆盖情况、更新 `game/assets.json`，并将独立运行包写入 `dist/`。运行包包含 `index.html`、`game/` 和使用到的 `assets/`，部署时需保持相对路径。

测试覆盖选择与结局可达性、结局优先级、首周目托菲路线、跨周目选项、存档恢复、回退、素材引用及快照大小。更详细的浏览器检查和验证边界见 [验证记录](analysis/validation.md)。

`dist/` 不包含素材研究室、分析报告、提示词或开发模拟存储。普通公网静态托管还需要配置独立存储适配器；当前项目默认支持下述本机与星匣两种运行方式。

## 存档与星匣接入

| 运行方式 | 存储行为 |
|---|---|
| 本机回环地址上的顶层页面 | 使用当前浏览器的 `localStorage` |
| 星匣平台或开发预览 iframe | 使用 GameSDK 的 `user` scope 云存储 |
| 其他公网独立页面 | 当前会尝试初始化平台 SDK；需要另行实现独立站存储适配 |

本机存档和平台存档分别保存，不会自动同步。可通过菜单导出 JSON 进度，再在另一种运行方式中导入。保存失败会显示提示；读取失败不会替换当前故事状态。

已安装并登录 star-letter CLI 后，可使用：

```sh
star-letter dev --open
star-letter check
```

`star-letter dev --open` 会生成当前开发会话的 `/dev/preview` 链接；链接以 CLI 当次输出为准。

平台配置位于 `star-letter.json`，构建入口为 `dist/`。开发模拟处理器是 `star-letter.mock.mjs`，模拟数据保存在被 Git 忽略的 `.star-letter-preview-store.json`；处理器和模拟数据均不进入正式构建。

当前仅声明并使用 **storage**，未接入 AI、支付、兑换或 OSS。存储适配器串行写入、使用版本检查，并对冲突、登录、限流、容量等错误显示对应反馈。真实平台登录与跨设备恢复需在星匣预览环境验收。

## 视觉素材与改编范围

公开原构建共有 407 个图片文件；本项目的中文版范围为 397 个，排除其他语言的 10 个标题或字幕文件。33 张最终图集覆盖其中 381 个新绘制槽位，另有 16 个菜单肖像或画廊缩略图复用新绘角色、背景；原本全透明的 18 个 GUI 组件保留透明语义。

交付图集使用内置 ImageGen 生成或修正，通过 UV 坐标显示单槽，没有通过程序裁剪或重画交付 PNG。各项尺寸、透明通道、SHA-256、提示词和源文件映射见 [生成素材清单](analysis/generated-assets.json)。部分 GUI 排列存在生成漂移，已测量并校准 UV；边框指标与细节不保证同原作一致。

原作图片仅用于研究与风格参考。运行包使用新生成的角色、场景、CG、界面和特效，不包含原作音乐、音效、字体及 Ren’Py 引擎。字体使用系统中文字体；重制版新增了可访问的糖果图鉴。

## 项目结构

| 路径 | 内容 |
|---|---|
| `index.html`、`game/` | 可玩的中文改编版、分支引擎、界面与存储适配器 |
| `assets/atlases/` | 最终新视觉图集 |
| `assets/cover.png` | 独立生成的草稿封面，提示词见 `prompts/cover.txt` |
| `prompts/` | 素材创建与修正提示词 |
| `preview/` | 素材、提示词及剧情结构查看器 |
| `scripts/serve.mjs` | 本地静态服务，包含路径检查与文件访问范围限制 |
| `scripts/build.mjs` | 素材索引更新与静态运行包构建 |
| `tests/engine.test.js` | 分支、恢复、素材引用及快照大小测试 |
| `star-letter.json` | 星匣草稿配置与能力声明 |
| `star-letter.mock.mjs` | 仅开发预览使用的存储模拟处理器 |
| `analysis/` | 玩法、画风、素材、结构图和验证记录 |
| `dist/` | 构建产物，由 `npm run build` 生成，不提交到仓库 |
